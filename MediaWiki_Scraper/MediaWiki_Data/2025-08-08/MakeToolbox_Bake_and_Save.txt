=Bake and Save=
==Overview==
[[File:BakeAndSave UI.png|499x499px]]

The '''Bake and Save''' is a utility for Autodesk 3ds Max designed to "bake" the complex, final animation of objects into a simple, keyframed format. It records an object's position, rotation, scale, (in '''WORLDSPACE''' coordinates) and visibility on every frame of a specified range and saves this data to an external XML Animation File (*.xaf).

This process is essential for simplifying complex animation setups (like those using rigs, constraints, or procedural controllers) into raw keyframes, making the animation easier to export, transfer to other objects, or use in game engines.

It is important to notice that this tool was primarily designed to be used in rigs that follow the '''best practices''' [[Vehicle Rigging in 3dsMax|described here]], with all geometry objects parented to driver nodes, which in turn are parented to control objects, like shown in the image below. It does not mean it cannot be used in other possible scenarios.

==How to Use==

=== Bake and Save an animation ===
#'''Open the tool''': From MakeToolbox, select the "BakeAndSave" from the scripts dropdown menu.
#'''Select Objects''': In your 3ds Max scene, select the object or group of objects whose animation you want to bake - following the best practices described above, select all the '''DRIVER NODES''' you wish to bake.
#'''Set Frame Range''': Click the '''"Snap to Timeline"''' button to quickly set the tool's start and end frames to match your scene's active timeline or manually enter the Frame Range using the available spinners
#'''Choose Options''': Choose to '''"Save Transforms"''', '''"Save Visibility"''' and/or '''"Create baked ref objs"'''.
#'''Bake Animation''': Click the '''"Bake and Save"''' button.
#'''Save File''': A file dialog will appear. Choose a location, name your animation file (e.g., "my_Animation.xaf"), and click '''Save'''. Be mindful of the options present on this save dialog to proper translate to your export needs.
#'''Process Complete''': Depending on the chosen options, your scene will be left intact or some '''Reference Objects''' (red boxes) will now show on your scene (if the '''"Create baked ref objs"''' option was selected).

=== Load an animation ===

# '''Open the tool''': From MakeToolbox, select the "BakeAndSave" from the scripts dropdown menu.
# '''Select Objects''': In your 3ds Max scene, select the object or group of objects whose animation you want to load on - following the best practices described above, select all the '''DRIVER NODES'''.
# '''Reparent the DRIVER NODES''': With the objects from step #2 selected, '''PARENT''' them to the '''GLOBAL''' node of your scene (as shown on the image above) or, '''alternatively''', unparent all the selected objects and make sure they are at the origin of your scene (0,0,0), their rotations are also zero (0,0,0) and their scale is the default [100.0,100.0,100.0].
# '''Load Animation''': Click the "Load" button.
# '''Select File''': A file dialog will open, select the appropriate *.xaf file and be mindful of the options present on this dialog to proper reflect your loading needs.
# '''Process Complete''': The '''DRIVER NODES''' (or other selected objects) should present the same animation pattern they had before, but are now independent of the '''CONTROL NODES''' they were previously parented to.

==User Interface (UI) Breakdown==
===Frame Range===
This section defines the time range for the baking process.
*'''Start/End Spinners''': Manually set the start and end frames.
*'''Snap to Timeline''': A button that automatically syncs the spinners with the active frame range on the 3ds Max timeline.
===Options===
These checkboxes control what data is baked.
*'''Save Transforms''': Bakes the object's '''position''', '''rotation''', and '''scale'''. This is the primary function and is enabled by default.
*'''Save Visibility''': Bakes the object's visibility property. The object must have a visibility controller for this to work (see Utilities).
*'''Create baked ref objs''': When checked, red box objects with the whole baked animation will be created and show on the viewport. This is useful either as a visual troubleshooter to assess if the animations (both PRS and Visibility track) are being correctly baked and/or can be used as new parent for the geometry objects initially parented to the '''DRIVER NODES'''.
===Bake and Save===
This section controls the main baking process.
*'''Bake and Save Button''': Starts the baking process and prompts you to save the *.xaf file.
*'''Progress Bars''': The top bar shows the overall progress through the frame range, while the bottom bar shows the progress of baking the selected objects within the current frame.
===Load===
This section is for applying a baked animation file to objects.
*'''Load Button''': After selecting objects in the scene, click this to open a file dialog. Selecting a *.xaf file will apply the saved animation to the selected objects.
===Utilities===
A set of helper tools to prepare your objects for baking or cleanup.
*'''Check sel for dupe names''': Checks if any selected objects share the same name, which can cause issues with the save and load processes. The results are show in a message box and printed to the MAXScript Listener.
*'''Add visibility tracks to sel''': Adds the necessary visibility controller to all selected objects so their visibility can be animated and baked.
*'''Delete animation on sel''': Removes all animation keyframes from the currently selected objects.
