When a project starts you need the following pieces of information answers.

* Establish Scope / Budget / agreements
* Collect scheduling deadlines feedbacks and milestones
* Logos / CAD / Deco / Legal / Scripts / Design Documents / Brand Guidelines etc - see the above link for more details

* Request Deliverable Specifications - see above link for more details
* Frame Rates / Resolutions / Usage cases ( for licensing and talent etc. ) / Aspect ratios
