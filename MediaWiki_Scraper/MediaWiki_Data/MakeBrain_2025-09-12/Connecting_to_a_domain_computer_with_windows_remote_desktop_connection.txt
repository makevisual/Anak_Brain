 
= Overview =
As of August 2024, all Make owned workstations and render nodes will be joined to the Active Directory Domain. This means that we can utilize Windows Remote Desktop Connection to connect to devices on the network instead of using VNC. 

= What is RDC = 

Remote desktop connection allows a single user to log into a remote computer at one time. Unlike VNC where a local user and a remote user can control the local computer, using remote desktop connection to connect to a workstation or render node only allows one user to connect to a computer at one time which provides a more secure experience. If a user tries to connect to a computer that someone else is already logged into, the user that is logged into the computer is prompted to allow or disallow the remote user from connecting to the computer.
= How to use it =
Remote Desktop Connection is available on all Windows 10, 11, and Windows Server based devices. To access Remote Desktop Connection from your computer in Windows 10, click the Start Button, scroll down until you find the folder "Windows Accessories", click the folder to expand it, then scroll down to Remote Desktop Connection and click its icon to launch it, or you can click the start button and start typing "remote" and select the icon once it populates in the search. <br>[[File:Remote_Desktop_Connection_Windows_10_Start_Menu.png|alt=Remote Desktop Connection Windows 10 Start Menu|553x553px]]<br>

For Windows 11, click the start button, start typing the word "remote" and select the Remote Desktop Icon when it appears. <br>[[File:1a.RenderNodeRDC.png|alt=To locate Remote Desktop Connection, click start then start typing "remote", then select "Remote Desktop Connection"|593x593px]]<br>

# Enter the Computer Name (Such as MAKE42, R199, etcc.) in the "Computer" box, then click "Show Options" in the bottom left corner of the window. This will make entering login credentials easier and will also allow you to save the credentials for faster access in the future. <br>[[File:RemoteDesktopConnection - IP.png|567x567px]]<br>
# For Username enter your AD Login ID in the format of: corp\LoginID then click the checkbox for "Allow me to save credentials." Then click Connect. <br>[[File:2.RenderNodeRDC.png|558x558px]]<br>
# Enter your current password when prompted and click OK. <br>[[File:3.RenderNodeRDC-Password.png|390x390px]]<br>
# The first time you connect to a workstation or render node, you will see a certificate warning - this is expected behavior. On the certificate warning pop-up you can visually confirm you are connecting to the correct render node or workstation. Click the checkbox "Do not ask me again for connections to this computer" and you will not see the certificate warning next time you connect. <br>[[File:4.RenderNodeRDC-Certificate.png]]<br>


You should now be connected to the render node and can perform tasks such as restarting the computer, installing software, restarting Deadline Worker, or any other administrative tasks you need to complete. Once you've completed your task(s), please close the connection so that others can connect to the render node if needed. An active connection from another user may prevent someone else from accessing the device <br>[[File:RemoteDesktopConnection - CloseConnection.png|1279x1279px]]

= Things to know =
* It will kick off whoever is signed in
* Desktops will look different for different users / credentials 
* VNC won't work as reliably
