=Making your own Article=

You can make an article for any topic needed, and you do not need permission or approval to create one. If you find yourself explaining a process or technique multiple times, that is a good indicator you may want an article to hold the information, as well as any media.

To do so, you simply need to create a link to a page, and follow it, to start editing. To create a link to a page, you simply type the desired name of the page, within brackets, like this, and a link to that page will be created. If that page already exists, clicking the link will take you there, if not, clicking the link will prompt you to create the page.

 <nowiki>
[[This is the name of my new article]]</nowiki>

Whenever creating a page you should follow the following standards and best practices to ensure a consistent and functional MAKE Brain.

=Standards and Best Practices=

=== Give your article a descriptive, and active name ===

The MAKE Brain is a repository for information regarding aspects ranging from production, animation, the physical office, IT, Software, Onboarding, and nearly anything else worth recording. Please take a moment to consider a concise, descriptive, and active name.

A name should be descriptive, so it can be differentiated from other similar articles. Additionally when describing a process with software, include the name of that software. That way if the process is changed to a different method in the future, the article can be differentiated, and we wont need to delete potentially useful information.

Giving an article an active name is a good idea, because many of the topics are processes or techniques. There are some that are documents, or information repositories, that a clear name should help distinguish. Below are some examples of poor names, compared to a better name that can be used.

* 'equipment' vs 'Ways to check out equipment'
* 'edit checklist' vs 'Review an edit for QC'
* 'exporting an edit' vs 'Encode a video using Adobe Media Encoder'

===Link to your article in multiple places===

The more places that your article is linked, the more useful it will become. If you are given an existing article to create, then it is already linked in some places. But if you are creating a new one, you will need to add it into some pages, or the main page, for it to be visible. There are other ways that an article can become vible as well. Here are some locations you can add links

* Main Page - The main page is organized to contain many groups of information. Find the appropriate area to add your link.
* Workflows - If you have a more specific article, or something that is part of a process, it can be linked in a 'workflow', which is a series of related articles that are presented in a progression, to help locate other, related, and relevant articles.
* Bread Crumbs - In other articles inline text [[TestPage|like this]] can link to [[Main Page|various places]]. You can add links like this to anyone's article if appropriate.
* Categories - Adding each article to a category is a good way of making it easy to locate related articles as well. If you are given a category, please add it. Otherwise you can find an existing one that is related to add. Note - A category should be the last thing on a page. An article may be the member of multiple categories.

===Considerations===

*Nothing is precious, articles can be created easily, you do not need permission to make an article!
*There are version histories, and backups of the articles, do not feel like you are stepping on any toes by making an edit or an update, previous versions can be restored if needed.
*As you are reading through the MAKE Brain, if you notice some information that is out of date, or incomplete, add to, or correct it. This is a living library that is only as useful as its content.

===Include and embed Media===

You can upload pictures and video to the Mediawiki, where it will be hosted, and is available site-wide. Anywhere you call the reference to the file on any page, it will be displayed. Files have histories, and their own pages as well. All the files must have a unique name, or they will cause conflicts with existing files. As you create content, it is important to give it a descriptive, unique name.

For starters, please save any media to the MAKE Brain location on the network. You can find that location here:
 <nowiki>
U:\MAKE_SITE\MakeBrain\Pages_and_Content</nowiki>
