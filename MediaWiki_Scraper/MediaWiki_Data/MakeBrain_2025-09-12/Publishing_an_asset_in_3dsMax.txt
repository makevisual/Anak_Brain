= Publishing an Asset=
===Preliminary Checks===
*Parent all geo and assign the correct multi/sub material to all geo + the global
*Freeze transforms
*reset geo pivots with Reset Xform modifier
*Collapse all modifier stacks (except Turbosmooth and Shell modifiers)

===Publishing with Asset Switch===
In order to publish through Asset Switch, you must have the global selected. Again, make sure all relevant objects and materials are parented and assigned to the global, or else they will not get published out.

Once you have the global selected, you will hit the publish button on the bottom left of the window.

[[File:Creating an asset AssetSwitch.PNG]]

This will take you to the Publish Center.

[[File:Creating an asset AssetSwitch PublishCenter.PNG]]

You will be presented with the options to export many different types of assets simultaneously. This is useful for making multiple formats of an asset, for example both XMesh and VRayMesh files with the same naming and animation at the same time, or publishing a full asset, a proxy version of it, animated caches, and a material, all with one click.

Preset naming conventions are included at the top for common classes of export, however this can be overwritten in the field below it, or a new preset can be set by clicking the "Presets" button to the right of the drop down.

The different export types have a check box to enable or disable what types of files will be generated by the publish. Names and folders are generated procedurally based off of the names passed. Check that the directory is going to the publish folder and the files will generated when the large 'Publish' button is pressed at the bottom of the window.

If you are going to publish more than once, be sure to check whether you are overwriting or versioning up, you will not be prompted when overwriting a publish. 

==Switching in an Asset==
Now that you have published an asset, you can bring it into any scene. You will have to select the correct asset file, select the correct material and vrmesh/max file before hitting << Switch Asset! >>

[[File:Creating an asset AssetSwitch Switch.PNG]]

This will bring in the max file and/or vray proxy depending on what you selected, along with its global. 

When you select the proxy geometry, you can change parameters to change the display preview of your proxy. 

[[File:Creating an asset AssetSwitch Proxy.PNG]]

By default, the Display tab will be set to "preview from file (faces)". This will be a reduced down proxy display for efficiency. You can change to other displays like a bounding box, up to showing the whole mesh.

It is good after you publish an asset to switch it in and double check that it published properly. To delete the asset you switched in, just double click the global (this will also select everything parented to your global) and delete.
